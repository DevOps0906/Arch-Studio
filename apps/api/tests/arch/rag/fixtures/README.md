# 예시(미확인) 픽스처

이 폴더의 코퍼스(`corpus/*.json`)와 평가셋(`eval_set.json`)은 **하니스 검증용 예시**다. 법령 문구·수치·시행일·관할 코드는
실제 원문이 아니며(수치는 `OO`), 모든 원본에 `is_example: true`가 붙어 있어 운영 ingest(`allow_examples=False`)가 거부한다.

실제 코퍼스·평가셋 30문항은 사람이 원문(국가법령정보센터, 자치법규, 지구단위계획 고시, 질의회신)을 확인해 만든다.
공공데이터 이용 조건·출처 표기 의무(D-14) 확인 후 `meta.attribution`을 채운다.
