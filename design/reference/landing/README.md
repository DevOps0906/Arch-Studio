# 랜딩 시안 (시각 참고용)

`landing.html`은 NOMAD 설득형 랜딩 템플릿(`nomad-design-modules`)이 만든 시안이다. **시각 참고용이다 (D-39, 2026-10-29).**

- 색·서체·여백·면 구성 같은 **시각 언어**만 참고한다.
- 문구·수치·가격·경쟁사·플랫폼 범위는 이 시안이 정본이 아니다. 시안에는 ADR-001 이전 사실("Windows 전용"), 확정되지 않은 가격, 타사 실명, 목표 수치(p95)가 들어 있다.
- 정본: `docs/file/03-설계/03_SCREENS_UX.md` 4.6·7장, `docs/file/02-요구사항/01_PRD.md` 6.1·9.7절, `docs/file/03-설계/ADR-001_DELIVERY_AND_LICENSING.md`.
- 시안의 fadeUp·blur 글자 등장·무한 글로우·CTA 타이핑·카드 기울임·숫자 카운트·외부 Google Fonts·미디어쿼리(560/900/1100/1180)는 포팅하지 않는다(DESIGN.md 6장, 반응형 3구간 토큰).
