6. pricing: 기존 apps/web pricing.test.ts가 2400만 읽음 → "유효 seed = 모든 modular 조각의 마지막 값"으로 확장. 15·40 리터럴 금지, 동등 비교만. CHAT_TURN_CREDITS·STT_CREDITS_PER_MINUTE는 seed 키 없음 → 범위 밖(기록). ai-settle 501·원가 정산은 범위 밖.
7. 라우터(source→feature 매핑, STT consult_recording 선택)는 아직 없음 → 단위 테스트는 후속(라우터 구현 작업의 완료 조건으로 기록).
8. 이 PC에 docker 없음 → DB 테스트는 PR CI db 잡으로 확인.
