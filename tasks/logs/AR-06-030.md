# AR-06-030 도면 시트 화면 `/projects/:id/sheets` + ExportDialog

- 근거: `06_AGENT_PLAN.md` AR-06-030 행, `03_SCREENS_UX.md` 3.8절·5.3절, `01_PRD.md` 9.4절.
- 구조: `packages/features/src/sheets/{index,parts,ExportDialog}.tsx`(화면), `model.ts`(순수: 시트 목록 저장·입력 누락·권리→화면), `runner.ts`(엔진 워커 sheet·export 레인 호출, 내보내기 순차 실행), `seq.ts`, `useProfile.ts`(031 표제란·레이어 프로필).
- 기하·도면 값은 화면이 만들지 않는다: 미리보기·내보내기 모두 drafting 워커(packages/drafting 순수 함수)의 결과만 쓴다. 미리보기 SVG = 직접 writeSvg(buildSheet) 와 같은 바이트(테스트).
- 데스크톱 워커: `drafting.handlers.ts`가 번들 글꼴·폭 표(loadAssets)로 PDF·PNG용 SVG를 만든다. 데모 모드는 `demo-rule-pack.ts`로 규칙 팩 공급.
- PNG: 어댑터 `rasterizer`(설치형 080)가 있을 때만 활성. 없으면 비활성 + 이유 표시(웹은 서버/resvg-js 연결 후). 형식 하나가 실패해도 나머지는 계속.
- 권리: view_export는 모든 상태 허용(실패 닫힘이면 잠금 안내). 편집 권리 없음(체험만료·구독만료)은 읽기 전용 + 마지막 시트 다시 내보내기만. 체험판 워터마크는 라이선스 상태로 정하며 화면에서 끌 수 없다.
- 상태: 로딩·빈·오류·권리 거부(LockedState) 4종, AR050·051·055~059 문구. 반응형 3구간 스크린샷 확인(가로 넘침 없음).
- 검사: lint·typecheck 통과, features 테스트 232건(시트 18건), 루트 pnpm test 통과, desktop build + check:release 0건.
## 문서와 다른 점 / 미해결
- 시트 목록은 프로젝트 파일이 아닌 localStorage(`arch.sheets.v1.<id>`)에 보관 — 프로젝트 파일 스키마에 칸이 없음(후속: 프로젝트 저장 연결).
- 일조사선 단면 시트는 엔벨로프 계산 연결 전까지 비활성(이유 표시).
- 웹 PNG 경로 미연결. 설치형 실기(Windows) 저장 대화상자·PNG 미확인.
