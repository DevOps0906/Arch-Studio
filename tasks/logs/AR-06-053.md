## 구현
- `apps/web/src/server/voice/**`, `apps/web/src/app/api/voice/stt/route.ts`
  - 받아쓰기(multipart, ≤60초·5MB): 실패 닫힘(제공자 없음 503, 인증 전) → 인증·레이트(조직 30/분, 제안)·member+·엔타이틀먼트 → 매직바이트(webm·ogg·wav·m4a)
    → `consume_credits` 1(`voice:<request_id>`) → 제공자 → 실제 길이 정산(`voice:<request_id>:settle` 환불) → 200 `{ text, duration_s, credits }`.
    제공자 실패 503·60초(+1초) 초과 413 `VOICE_TOO_LONG`은 전액 환불. 환불된 요청 재전송은 409(제공자 재호출 방지). 원본 저장 안 함.
  - 상담 녹음(JSON): 고지 버전 = `ARCH_RECORDING_NOTICE_VERSION`(아니면 422 `recording_notice_required`), ≤7200초, `ai_intake`, consult_audio 경로·크기(50MB)·매직바이트 재검사
    → 신고 길이 선차감 → `core.voice_jobs`(id=request_id, store_audio, 24시간 expires_at, third_party_notice) + `enqueue_job('arch.stt', max_attempts 2, credit_ledger_id)` → 202.
  - 제공자 어댑터: oss-voice(`OSS_VOICE_BASE_URL/stt`, 사용자 voice 토큰), mock(development·test). 서명 키 없음 → 제공자 실패 → 환불 503(실패 닫힘).
- `workers/arch-jobs/src/handlers/stt/**`: payload 검사 → 원본 내려받기·재검사 → 제공자(대체 없음, 1회 재시도) → 전사본 `org-files/<org>/arch/stt/<job_id>.json` → 실제 길이 정산 환불 → jobs.result.
  `register.ts buildSttHandler(env)`: `ARCH_VOICE_CONSULT_ENABLED=true` + mock(dev·test)일 때만 핸들러(웹 접수도 같은 조건).
- `packages/features/src/voice/**`: `model.ts`(상태 리듀서·권한 오류 분류·안내 문구·postDictation·읽어 주기), `index.tsx`(VoiceButton·ReadAloudButton).
- `.env.example`: `ARCH_VOICE_STT_PROVIDER`, `ARCH_VOICE_CONSULT_ENABLED` 이름만.

## 보안 리뷰 수정(REQUEST_CHANGES 반영)
- 🔴 request_id 재사용 무료 STT: 차감 키를 `voice:<org_id>:<request_id>`(정산 `...:settle`, 잡 `job:arch:voice:<org_id>:<request_id>`)로 조직 범위 한정.
  consume_credits는 같은 키면 기존 원장을 그대로 돌려줘 반환값으로 새 삽입을 구분할 수 없다 → `p_metadata.nonce`에 호출마다 새 값을 넣고 원장 행을 다시 읽어
  nonce·org·actor·amount·mode가 모두 이번 요청과 같을 때만 통과. 그 밖(재전송·환불된 원장 재사용·받아쓰기 원장으로 상담·다른 사용자)은 제공자·enqueue 전에 409 `voice_request_done`.
  DB 제안(supabase/** 금지라 제안만): consume_credits가 `inserted boolean`을 함께 돌려주면 재조회·nonce가 필요 없다.
- 🟠 워커: 실제 길이 > 신고 × 1.1이면 `STT_DURATION_MISMATCH`(재시도 없음)로 실패 → fail_job이 잡 원장 남은 금액 전액 환불. 전사본 저장·부분 환불 안 함.

2. `packages/features/package.json` exports `"./voice"`는 팀장이 직접 반영했다(424e856). 채팅(055)·대화형 입력(3.6절) 화면 연결은 각 작업에서.
