# AR-06-053 음성: 받아쓰기·음성 UI·읽어 주기

## [DECISION] 착수 전 (2026-11-02, 팀장 — 사용자 방침 "막히면 기록하고 계속") — challenger REVISE(🔴4 🟠5 🟡4) 반영
1. **범위 축소**: 053 = 동기 받아쓰기(`POST /api/voice/stt`, voice_chat) + 음성 UI + 읽어 주기. **상담 녹음(워커 arch.stt·consult_recording·audio_path·24h 삭제·50MB)은 052로 이관**(PRD:60 P1). 052 착수 때 challenger 🔴4(audio_path 조직 접두·존재·크기·매직바이트 재검사)·24h 삭제 보장·버킷 형식/비트레이트 고정·consume↔enqueue 원자성을 완료 조건으로.
2. 멱등(🔴1): 키 `voice:<org_id>:<request_id>`. consume_credits가 기존 원장 행(중복)을 돌려주면 **제공자 호출 없이 409 IDEMPOTENT_REPLAY**. 결과 텍스트는 저장하지 않음(원본·결과 미저장 원칙).
3. 길이(🔴2): 받아쓰기는 **요청당 1크레딧 정액**(≤60초 = 분당 1 올림 1). 바이트 상한 5MB + 제공자에 max_seconds=60 전달(초과분 잘림). 제공자가 돌려준 duration이 60 초과면 결과 폐기·전액 환불. 0초·무음(빈 전사)은 전액 환불(refund_credits). 정산 순서: 동기 경로라 fail_job 없음 → CR003 함정 해당 없음.
4. 마이크 헤더(🔴3): apps/web에는 마이크 UI가 없다(스튜디오는 apps/desktop Vite 웹 빌드, D-071a) → next.config `microphone=()` 유지. 스튜디오 웹 호스팅 헤더는 071, 데스크톱 WebView2 마이크 권한은 실기 확인(사람). UI는 권한 거부·미지원 시 텍스트 입력으로 계속.
5. 차감 직접 호출 검사(🟠): start-run.test.ts 허용 목록에 server/voice를 04_API:14 STT 예외로 명시 추가.
6. oss-voice 인증(🟠): 제공자 프로토콜에 토큰 공급 함수 주입(scope=voice). 실제 제공자·토큰 발급 연결은 후속(가짜만). 과금 경로 킬 스위치 `ARCH_VOICE_STT_ENABLED` 기본 off.
7. intake 연계(🟠): 받아쓰기 결과는 텍스트로 intake(source='chat') 입력에 넣는다(stt_job_id 없음).
8. 전송(🟡): api-client에 바이너리(raw body + Content-Type audio/*) 전송 최소 추가. multipart 미사용.
9. 읽어 주기(🟡): OS 음성 합성, 한국어 음성 없으면 버튼 숨김 + 테스트. 0크레딧.
10. 사람 확정 대기(제안값으로 진행): 정액 1/요청, 무음 환불, ElevenLabs 대체 단가(미연결이라 보류), 스튜디오 S 호출 허용(허용으로 진행).
