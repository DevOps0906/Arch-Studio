# AR-06-007 — 클라우드 API 클라이언트(Bearer, 재시도 대기열, 오류 코드 매핑)

근거: `06_AGENT_PLAN.md` AR-06-007 행, `04_API.md` 1장(원칙)·7장(오류 코드), `03_SCREENS_UX.md` 5.2·5.3절.
코드: `packages/features/src/api-client/**`.

## 코어 요청 R-A6·R-A7 보류 조건
이 작업은 **Route Handler를 실제로 부르지 않고** 클라이언트만 제공한다(호출 코드는 008 이후 화면에서). 따라서 "R-A6·R-A7 반영 전 Route Handler 호출 머지 보류" 조건은 충족. 실제 호출을 붙이는 작업은 해당 조건을 다시 확인해야 한다.

## 설계 결정
- 토큰은 주입된 `getAccessToken(): Promise<string | null>`로만 얻는다. shell-bridge import 없음. null·빈 문자열 → `unauthenticated`(호출 없음). 401 응답도 재시도 없이 `unauthenticated`.
- 시계·fetch·sleep·난수(`jitter`, `genId`)·온라인 여부(`isOnline`)가 모두 주입. 기본 backoff는 `min(maxDelay, 500·2^(n-1))` + `jitter(backoff)`(기본 0, 결정적). `Retry-After`(초 또는 HTTP 날짜)가 더 길면 그 값.
- 대기열은 FIFO 직렬(동시 1건): 오프라인(`isOnline()===false`)이면 맨 앞이 `notifyOnline()`까지 기다리고 뒤 요청은 순서를 지킨다. 같은 `idempotencyKey`가 대기·처리 중이면 새 전송 없이 결과를 공유(중복 제거). 요청 하나의 총 대기 상한 `maxWaitMs`(120s), 건수 상한 `maxQueue`(50), 시도 상한 5회. 상한 초과는 `queue_expired`·`queue_full`.
- 자동 재시도: 네트워크 오류·408·429·5xx. 단 **알려진 AR/CR/AI 코드가 붙은 응답은 재시도 안 함**(AR004·AR034 같은 429, AR021 502, AR033 500 포함). 예외로 `rate_limited`·`AI_UNAVAILABLE`은 재시도. `AR021`은 자동 재시도는 안 하되 `retryable=true`(사용자가 다시 조회 가능).
- 취소: `AbortSignal`. 같은 멱등 키를 공유한 호출자는 각자 취소되고 모두 취소돼야 실제 전송이 중단된다.
- 금지 필드: 타입(`JsonObject`가 `org_id`·`amount`·`credits`·`price` 등을 `never`로 막음, 중첩 포함) + 런타임 방어(키 정규화 비교 후 `forbidden_field`, 값은 오류에 싣지 않음). 컴파일 오류 검증은 `types.check.ts`(`@ts-expect-error`, typecheck가 돌림).
- 멱등: 변경 메서드는 `idempotencyKey` 필수(타입+런타임). 헤더 `Idempotency-Key`로 보낸다.
- 오류: `ApiError{code, httpStatus, retryable, userMessage, actions, details}`. 원 응답 본문·서버 message·요청 본문·토큰 미포함. `details`는 허용 목록(reason·can_download·required·balance·available_at)만. 로그 이벤트는 id·method·경로(쿼리 제외)·시도·상태·코드뿐.
- zod 의존성 없이 `parse?: (data) => T` 훅(zod는 `(d) => schema.parse(d)`로 연결). 검증기 예외 메시지는 버리고 `invalid_response`만.

## 04_API/03장과 다르게 한 점
1. 멱등: 04장 1장은 **본문 `request_id`**. 클라이언트는 추가로 `Idempotency-Key` 헤더를 보낸다(서버가 읽는지는 047에서 확정 필요; 읽지 않아도 무해). 본문 `request_id`는 호출자가 넣는다.
2. 03장 5.2절에 없는 코드의 문구는 이 작업이 만든 제안값: `AR044`·`AR045`(사유별)·`CR001`·`AI002`·SQLSTATE(42501 등)·앱 코드 7종·402 `no_product`/`fallback`·`AR060`·`AR061`. 팀장/UX 확인 필요.
3. 03장 5.2절의 `[버튼]`은 문구에서 분리해 `actions` 배열로. `AR041` 문구는 대괄호를 문장 안으로 풀었다. `AR040`의 `<n>`, `AR054`·`AR058` 등의 `<…>` 자리표시자는 제거한 개수 없는 문구(상세는 화면이 덧붙임).
4. 402 `entitled=false` 응답의 envelope `code`가 04장에 정해져 있지 않다. `details.reason`이 있고 코드가 없으면 합성 코드 `entitled_false`로 처리(`AR044`와 같은 사유별 문구).
5. 클라이언트 자체 코드(서버 계약 아님): `unauthenticated`·`network_offline`·`server_error`·`aborted`·`queue_full`·`queue_expired`·`invalid_response`·`forbidden_field`·`http_<status>`.
