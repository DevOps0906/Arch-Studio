# AR-06-038 프로그램 화면

## 2026-10-30 — 수동 면적표 편집

- 기존 체크리스트 답·면적표 표시, 실 추가·수정·삭제와 행 잠금, 프로젝트 저장을 연결했다.
- 직접 수정한 행은 잠근다. 이름 변경 시 잠금 식별자도 새 이름으로 저장한다. 공백 정규화 후 이름 중복·빈 이름/용도·잘못된 면적은 저장 전에 거부한다.
- 편집 권한 미확인/거부 때는 열람만 가능하다. 기존 ProjectStore와 expectedVersion을 사용하며 충돌 시 입력을 유지하고 최신 버전 다시 열기를 안내한다.
- 기하·체크리스트 답은 보존한다. 단가 미연결 상태는 비용 수치 대신 안내로 표시한다.
- 검증: features 타입 검사·린트, program/model 테스트 3건 통과(기존 데이터 보존, 이름 변경·잠금, 잘못된 입력·손상 모델 거부).
- 미검증: 브라우저 3구간 시각 확인과 실기 저장 시나리오.
- 남음: 승인된 체크리스트 질문/ProgramRuleSet 연결·잠금 제외 재계산, 단가 조회·등급 선택·출처와 기준일 표시·공사비 엔진 연결. 전체 완료가 아니다.

## 2026-10-30 — 공사비 API·엔진 연결

- 단가 조회 API를 ApiClient로 호출한다. 로그인/조직 미확인·오프라인·조회 중·오류·204 응답을 구분하고 오류 시 재시도를 제공한다. 요청 취소와 조직 변경 시 이전 단가 숨김을 적용한다.
- 단가 버전·실제 날짜·출처·안전한 정수 단가·중복 항목을 검증한 뒤 기존 `@arch-studio/program` 엔진으로 계산한다. 새 외부 의존성 없이 내부 workspace 의존성만 추가했다.
- 구조·마감 등급은 카탈로그 항목에서 선택하며 기준일·출처·버전을 표시한다. 공급가액·부가세·합계를 표시하되 단가 누락 실이 있으면 전체 합계 대신 누락 안내를 보인다.
- 실제 단가 자료는 새로 만들지 않았다. 카탈로그 캐시·자동 체크리스트 재계산과 실기 검증은 후속이다.
- 검증: features 타입 검사·린트와 전체 테스트 270건 통과(프로그램 5건 포함). 설치 캐시 손상은 별도 캐시로 기존 버전을 재설치해 복구했다. 3구간 캡처는 `scripts/shot`의 Playwright 패키지가 없어 실행하지 못했다.

## 2026-11-01 — 체크리스트 답 수정·잠금 제외 재계산

- 체크리스트 질문(예/아니요·수량·선택)을 편집하면 `@arch-studio/program` `buildProgram`으로 면적표를 다시 계산한다. 잠긴 행은 값·위치를 유지하고, 잠기지 않은 행은 규칙 결과로 대체한다. 답과 면적표를 함께 저장한다(`withRows`에 답 인자 추가).
- 잠긴 행 입력이 잘못됐거나 답으로 계산할 수 없으면(RangeError) 답을 반영하지 않고 경고만 보인다.
- 정본 규칙 세트·질문이 미결정이라 공급 자리(`program/rules.ts` `provideProgramChecklist`)만 두고, 공급원은 개발 데모뿐이다: `demo/program-rules.ts`(실 목록·면적 모두 '개발용' 지어낸 값)를 `createDemoRuntime`이 공급한다. 데모 모듈은 042 개발용 규칙 팩과 같은 조건(DEV + VITE_DEMO_MODE=1 동적 import)으로만 로드되어 릴리스 번들 0.
- 운영(공급 없음)은 '규칙 세트 미연결' 안내와 저장된 답 열람만, 면적표 직접 입력은 그대로.
- 검증: features lint·typecheck·test 274건 통과(새 4건: 공급 게이트, 재계산, 잠금 유지·저장, 잘못된 입력 거부). desktop 릴리스 빌드 후 `check:release` 통과(데모 표식 0).
- 미검증: 3구간 캡처 — `scripts/shot`의 playwright가 어떤 manifest에도 없어(lockfile 범위 밖) 설치하지 않았다. 릴리스 dist에서 개발용 규칙 세트 문구 직접 검색은 dist 읽기 제한으로 못 했다(데모 모듈 표식 검사로 갈음).
- 리뷰 반영: 수량 칸은 반영 실패 때 저장된 답으로, 잘못된 글자는 blur 때 되돌린다(화면 = 저장값). 선택 질문에 항상 '선택 안 함'을 두고 고르면 답을 지운다. 테스트 275건 통과.
- 남음: 승인된 체크리스트 질문·ProgramRuleSet 정본과 운영 공급 경로(서명 검증 등), 엔벨로프 최대 면적 대비 합계 표시, 카탈로그 캐시, 실기 저장 시나리오.
