- 지역: 팩 `municipalities`에 없는 지자체 → 확정 규칙도 WARN `UNSUPPORTED_REGION` + `MUNICIPALITY_NOT_IN_PACK`("조례 미확인 지자체") 경고. 목록에 있으나 조례 미확인 → `ordinance_dependent` 규칙만 WARN `ORDINANCE_UNVERIFIED`(값·한도는 참고로 유지).
- `roads.edge_index`: 정규화 전 원래 외곽 순서(outer[i]→outer[i+1])로 매핑(사용자 결정 2026-10-29). 시계 방향 대지 테스트 포함.
- 이격 비교는 정확 제곱 거리 + `compareDistance`(표시 1500mm·실제 1499.6mm → FAIL 테스트). 면적 비율은 2배 면적 bigint 정확 비교.

## 팀장 확인 필요
1. JudgmentResult 계약에 행 문구·규칙 id 칸이 없어 "확인 필요" 사유는 `details[i].reasons`(+`REASON_MESSAGES`)·`warnings`로 별도 반환.
2. 미확인 행 basis는 `law/article/effective_from = "미확인"`(빈 배열 아님) — 화면에 표시되는 "근거 없는 행 0" 정의와 맞는지.
3. 산정 가정(원문 대조 전): 건축면적 = 지상층 매스 외곽 합집합(다중 매스는 union 교차점 정수 스냅이라 1스냅 단위 오차 가능), 지하층 전용 매스는 대지 밖 검사·이격 측정 제외, 용적률 연면적 제외 항목 = 팩 far 규칙 `params.far_floor_area_exclusions`(현재 선택지 `basement`; 미확인 규칙은 지하층 제외 + reasons `FAR_EXCLUSIONS_UNVERIFIED` "산정 제외 항목 미확인"), 높이 = base + 지상 층고 합, 주차 바닥면적 = 전 층 용도별, 주차 소수 처리 = 합산 후 1회(팩 `rounding`), 대상 여부 = 층수·연면적 기준 OR. 대상이면 WARN, 아니면 NA. 주차는 산정만(NA).
4. `rule_context.ordinance_applied`는 쓰지 않음(팩 지자체 상태로만 판단). 일조사선은 판정 엔진에서 계산하지 않고 WARN(엔벨로프 AR-06-016).
5. `.gitattributes`(쓰기 범위 밖): `core.autocrlf=true`라 `packages/rules/packs/**`·`golden/**`가 CRLF로 체크아웃되면 sha256·바이트 비교가 깨진다. `eol=lf` 추가 필요. 테스트는 CRLF를 LF로 읽어 임시 대응.
6. 팩 소스 저장소 위치(02_ARCHITECTURE rule-pack-data "팀장 결정 필요")와 서명 대상 바이트(현재 매니페스트는 pack.json 정규 바이트 sha256) 확정.

## 리뷰 반영 (2026-10-29, ACCEPT 🟡)
- manifest 스크립트 경로 manifest.ts로 수정, `pnpm --filter @arch-studio/rules manifest packs/2026.10.0 --check` 통과.
- 로더: basis에 `ordinance: true`가 있으면 `ordinance_dependent: true` 필수(거부 테스트).
- 용적률 지하층 제외 하드코딩 → 팩 params `far_floor_area_exclusions`. 측정은 지상·지하 면적을 따로 낸다. 골든 재생성(배포 팩 far 행 reasons에 `FAR_EXCLUSIONS_UNVERIFIED` 추가가 변경 이유).
- 🟢 최단거리 geometry 재사용은 보류: `distance()`는 다각형 둘만 받고(면적 0 거부) 선분(대지 변) 입력이 없어 정확값이 같게 대체할 수 없다. 비교는 이미 `compareDistance` 사용. 바꾸려면 geometry에 선분–다각형 거리 export 필요(다른 패키지 수정이라 팀장 결정).
