# AR-06-020 로그 — 시트 모델(sheet/validate·fit·assemble, titleblock, layers, annotate)

## [DECISION] 후보 — SheetSpec.annotation_overrides `dx_mm`·`dy_mm` 단위 = **용지 mm** (팀장 확인 필요)
- 근거: 02_ARCHITECTURE.md 2.3절 "정밀도 설명"(용지에 고정된 요소는 0.01mm 정수), DraftingProfile `default_text_height_mm`도 용지 mm(04_API.md 4.7.3). 덮어쓰기의 목적(문자·치수 겹침 피하기)은 용지 위 현상이라 축척이 바뀌어도 문자 크기 대비 같은 간격이 유지돼야 한다.
- 규칙: 실수 허용, `roundHalfAway(dx_mm × 100)` → 0.01mm 정수. 뷰 주석(모델 mm)은 × 축척/100(분모가 100의 배수라 정수 그대로), 용지 주석은 그대로 이동.
- `note:<id>` target = 자유 메모. 위치는 용지 좌표 (dx_mm, dy_mm)(용지 왼쪽 아래 원점), `A-ANNO-TEXT`, 줄바꿈 있으면 MTEXT.
- 대안: 모델 mm(정수) — 축척 자동 변경 시 화면상 이동량이 달라지고 메모 위치를 정할 수 없어 택하지 않음.
- 반영 필요: 04_API.md 4.7.3 주석(`dx_mm`·`dy_mm`: 용지 mm), 05_DATA_MODEL.md 236행, tasks/README.md 106행 모호점 닫기(쓰기 범위 밖이라 미반영).

## 계약 보충(팀장 확인 필요)
- `Annotation.view_id?`: 계약의 `Prim<Mm | PaperUm>`만으로는 좌표계를 알 수 없어 추가. 있으면 그 뷰의 모델 mm, 없으면 용지 0.01mm.
- `DraftingInput`에 `project_name`·`date`(YYYY-MM-DD) 추가: TitleBlockValues에 필요하지만 02장 DraftingInput에 없음. 엔진은 시각을 읽지 않음.
- source_ref 필수 대상(팀장 결정 2026-10-29로 좁힘): 엔진 계산 값만 — `dim` 주석의 TEXT 전부(MTEXT 불가), label·warning의 값 줄(`kind: "value"`, 면적·판정 수치). 실명 "침실2" 같은 일반 줄·뷰 TEXT는 대상 아님. 표제란 값 TEXT에는 참고로 source_ref를 단다.
- 덮어쓰기: 엔진 주석에 `text`는 항상 거부(unapplied `text_not_allowed`, 위치·숨김은 적용). 표제란은 paper_prims라 대상이 아님(`missing_target`). 결과는 `buildSheet` 반환의 `unapplied_overrides`(SheetModel에는 칸이 없음).
- AR058이어도 시트는 만든다: 자동이면 1/600, 고정 축척이면 그 축척 그대로 + warnings AR058(조용히 바꾸지 않음).
- 여러 뷰는 합친 경계 상자로 축척·원점 하나를 쓴다(MVP 시트는 뷰 1개).
- 여백 철하는 쪽 25mm는 가로·세로 모두 왼쪽. 예약 폭(제안): site_plan 80mm, area_plan 120mm.
- input_hash: 키 정렬 정규화 JSON의 sha256을 동기 순수 구현(`sheet/hash.ts`, node:crypto 기준값 테스트). lib에 DOM이 없어 UTF-8 인코더도 직접 둠.
- 범위 밖으로 둔 것: 방위표·축척 막대(AR-F-028, A-ANNO-NRTH) — 뷰/표제란 후속 작업에서. 글자 폭 검사는 022 글꼴 폭 표 이후.

## 리뷰 반영 (2026-10-29)
- 고지 글자 높이: 최소 2.5mm(`DISCLAIMER_MIN_H`), 프로필 값이 더 크면 그 값. **근거 미확인** — PRD 9.7절에 글자 크기 기준이 없어 정한 값. 0.01mm 반올림이 0 이하인 `default_text_height_mm`(예: 0.001)은 validate가 AR050, titleblock이 INVALID_ARGUMENT. `assertDisclaimer`는 A-TTLB·문구 동일·높이 ≥ 2.5mm를 확인.
- 경계 상자: ARC = 시작·끝점 + 지나는 사분면 극점. 끝점 cos·sin은 Math 초월함수 대신 고정 계수 테일러 다항식(사칙연산만, 90° 배수는 정확한 정수) 후 roundHalfAway. INSERT = 블록 정의를 회전(90° 배수만, 그 외 명시적 오류)·이동해 포함, 배율은 계약에 없어 1. 블록 누락·순환은 INVALID_ARGUMENT.
- 축척 속성 테스트는 용지 치수 리터럴 기대식(w ≤ 275×분모, h ≤ 207×분모)으로 독립 계산.
