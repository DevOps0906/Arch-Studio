  → resolve_refs(치환, 엔진 값·인용 조문 번호 밖 숫자는 1회 재작성 후 제거) → compliance → output(ReviewResultV1 strict). 자료 0건이면 LLM 호출 없이 AR033.

- `apps/web/src/server/ai/review/**`, `apps/web/src/app/api/ai/review/route.ts`: 스위치(503) → 인증 → 본문 ≤256KB strict → 레이트 10/분(제안) → member+

  클라이언트 judgment·model_summary는 받기만 하고 저장하지 않는다. model_summary는 서버 measure 값 + ordinance_unverified.
- `workers/arch-jobs/src/handlers/review/**`: 잡 토큰 → POST /graphs/arch.review/runs → GET 폴링(stage 하트비트, 401 시 토큰 1회 갱신) → 결과 사전 검사(AR033) → runResult.
  10분 초과는 러너 정책(재시도 1회 후 fail_ai_run 환불).
