## [DECISION] 착수 전 (2026-11-02, 팀장 + 사용자) — challenger REVISE(🔴3 🟠2 🟡2) 반영
1. 데이터 경로 = **워커 중계**: 워커가 arch.reviews의 서버 재계산 판정을 읽어 FastAPI에 본문으로 넘기고, FastAPI(DB 권한 없음)는 결과·오류 코드를 GET 응답으로 돌려준다. finish/fail_ai_run·ai_usage 기록은 워커. 02_ARCH:360·04_API:517·6.3절("output 노드가 finish_ai_run") 정정 필요.

3. 그래프 = **순수 Python 노드 순차 실행**(LangGraph 미도입). 재시도는 (job_id, attempt)로 새 실행, 처음부터 재실행. 문서 "같은 thread로 재개" 정정.
4. 타임아웃 = **요청부터 전체 10분**(재시도 포함). 시도당 상한 = 남은 시간. 초과 시 중단·전액 환불.
5. 기본값(팀장): 과금 경로 킬 스위치 기본 off — web 라우트와 워커 핸들러 등록 둘 다(render/config.ts 방식). 실제 LLM 제공자 미연결(가짜만, 049 미병합). 단가 15 제안 유지.
6. AR033: 그래프 cite_check + 워커 이중 검사 — 남는 문장 0이면 AR033, 출처 id는 이번 retrieve 결과 청크 집합 소속만 허용(지어낸 id 제거). 테스트 필수.
7. FastAPI 실행 저장소가 메모리라 404 가능 → 워커는 404를 재시도 가능 오류로 분류(전체 10분 안).
8. 환불: 최종 실패 환불은 기존 경로(enqueue refund_on_failure → fail_job → fail_ai_run). ai-settle(차액 정산)은 정액이라 범위 밖.
9. 순서: (A) api 그래프·compliance·계약 스키마 → (B) web 라우트·재계산·팩 검증 + 워커 핸들러. 위험 높음 → 변경 후 reviewer(code)+reviewer(security/contract).

## [RESULT] (A) FastAPI 그래프·compliance·실행 계약
구현: `apps/api/app/ai/graphs/arch_review.py`(노드 순차, `ArchReviewRunner`), `app/ai/compliance/arch.py`, `routes/graphs.py`, `runs.py`, `schema.py`(ReviewRunInput/ReviewRunResult/ReviewLlm*). 새 의존성 없음. 기본 앱(`create_app`)은 NotConfiguredRunner 그대로: 실제 LLM 제공자 미연결이라 `ArchReviewRunner`는 주입할 때만 동작.

### 계약
POST `/graphs/arch.review/runs` (잡 토큰 scope `graph:arch.review`, 토큰 `run` == 본문 run_id). 본문 strict, org 키 거부(org는 토큰에서만). 실행 키 = (job_id, attempt): 같은 attempt 재POST는 기존 실행 반환(202, 재실행 없음), 새 attempt는 새 실행(처음부터), 같은 run_id에 다른 job은 409.
```json
{"run_id":"33333333-3333-4333-8333-333333333333","attempt":1,"application_date":"2025-01-01","timeout_s":600,
 "judgment":{"engine_version":"1.0.0","rule_pack_version":"2025.1","application_date":"2025-01-01","pending_changes":0,
  "items":[{"key":"coverage","verdict":"FAIL","value":65,"limit":60,"unit":"pct",
   "basis":[{"law":"가상건축법","article":"건폐율","effective_from":"2024-07-01","ordinance":false}]}]}}
```
`timeout_s`(1..600, 기본 600)는 시도당 상한 = 전체 10분 중 남은 시간. 응답 202: `{"data":{"graph_run_id","graph","run_id","status":"accepted","attempt":1}}`.

GET `/graphs/runs/{graph_run_id}` 성공:
```json
{"data":{"graph_run_id":"...","graph":"arch.review","run_id":"...","status":"succeeded","attempt":1,
 "result":{"review":{"schema_version":"review.v1","rule_pack_version":"2025.1","disclaimer_version":"arch-review-disclaimer.v1",
   "items":[{"key":"coverage","verdict":"FAIL","engine_value":{"value":65.0,"limit":60.0,"unit":"pct"},
     "sentences":[{"text":"65이(가) 한도 60와 비교됩니다.","source_ids":["law-cov-v2#0"]}]}],
   "needs_check":[],"sources":[{"id":"law-cov-v2#0","law":"가상건축법 건폐율","article":"","effective_from":"2024-07-01","kind":"law"}]},
  "refs":{"coverage.limit":60.0,"coverage.value":65.0}}}}
```
실패: `{"data":{...,"status":"failed","attempt":1,"error":{"code":"AR033","retryable":false,"stage":"interpret"}}}`. code = AR033(false) | PROVIDER(true: LLM·검색 오류·시간 초과) | INVALID_INPUT(false: 날짜 불일치·중복 키). stage = load|retrieve|interpret|compliance. 예외 메시지는 담지 않음. 실행 없음/타 조직/타 잡 = 404(워커는 재시도 가능으로 분류, 결정 7).

### 동작
- select_items: FAIL·WARN·NA(→CHECK)·PASS이나 value>=limit*0.95. 선택 0이면 LLM 호출 없이 빈 items로 성공.
- cite_check: 출처 id는 해당 항목 retrieve 청크 집합 소속만. 남는 문장 0이면 AR033(resolve_refs·compliance 뒤에도 0이면 AR033).
- resolve_refs: `{ref:<key>.value|limit}`만 치환. 모르는 경로·엔진 값(+인용 출처 제목 숫자) 밖 숫자는 LLM 1회 재작성 후 제거.
- compliance: FAIL 규칙(인허가 보장·허가 단정·적법 단정·전문가 대체·공공기관 보증) 문장 차단, WARN은 needs_check로 이동.
- 기존 테스트의 arch.review 시작 본문을 `tests/conftest.py review_body()`로 교체.
- 검증: pytest(zod 동치 제외) 전체 통과, ruff check/format, mypy app tests 통과.

- 순서: 스위치 → 인증 → 본문 256KB(초과 413 AR031) → zod strict → 레이트(조직 10/분) → member+ → 엔타이틀먼트 → 본문 rule_context 일치(불일치 422) → eligible_rule_packs 대조 → 매니페스트 대조+Ed25519 서명 → 팩 sha256·bytes → judge() 재계산 → start_ai_run(review/review, options = rule_pack_version·application_date·municipality_code·judgment(서버 계산)).
- 본문 `judgment`(데스크톱 값)는 허용만 하고 버린다. model_summary는 보내지 않음(DB가 {}로 채움). pendingChanges는 0.
- 테스트 11건(service.test.ts): 정상·judgment 불신·킬 스위치·256KB·서명 실패(다른 키/미주입/모르는 kid/형식 오류)·팩 변조·자격 없음·rule_context 불일치·모양 오류·멱등·권한.
