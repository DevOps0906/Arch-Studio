## 상수 근거
- `VWORLD_CALL_TIMEOUT_MS = 4000`: 04_API 6장 "호출당 4초 타임아웃·재시도 1회".
- `SITE_LOOKUP_DEADLINE_MS = 4500`: p95 5초(AR-F-001) 안에 세션 확인·DB 기록·응답 직렬화 몫 0.5초를 남긴다. 주소 조회는 호출 3번(지오코딩·필지·용도지역)이라 각 호출은 `min(4초, 남은 시간)`.
- `VWORLD_MAX_RESPONSE_BYTES = 1MB`: 필지 1건 경계(최대 2,000점 × 약 40바이트 ≈ 80KB)의 10배 이상 여유.
- 버스트 리밋 조직당 20회/분: 일일 상한(최대 30)보다 작게, 정상 사용(재조회·형식 오류)에는 넉넉하게.

## 서비스 롤 사용 지점
- `arch.record_site_lookup`만(`supabase-repo.ts`). 함수가 `core.is_privileged_session()`을 요구(2400_arch.sql 7-6)하고 `site_lookups`에 사용자 GRANT가 없어 다른 방법이 없다. 인자는 세션 org·HMAC 해시 둘뿐.
- 세션 확인은 사용자 JWT 클라이언트(`bearerGatewaySession`, 040·업로드와 같은 경로).

### 방어 없는(남은) 항목
- A3 버스트 리밋은 메모리 저장소(인스턴스별)라 다중 인스턴스에서는 인스턴스 수만큼 느슨해진다. 일일 상한 자체는 DB라 영향 없음. 040과 같은 후속(공용 레이트리밋 저장소)으로 교체.
- A5 자기교차 검사는 서버가 하지 않는다(화면이 geometry `normalizePolygon`으로 거부). 서버 응답을 직접 쓰는 다른 클라이언트가 생기면 서버 검사 추가 필요.
- A9 VWorld 실제 지연 분포는 키가 없어 측정하지 못했다(p95 5초는 설계 값).
- 해시 키 길이(32자 이상)는 서버 코드가 강제한다. env 스키마는 `min(1)`이라 짧은 키로 기동은 되고 조회만 503 → env 스키마 쪽 강화 요청(아래).

## 결정·문서와 다른 점
1. **mm 변환 위치**: 지시는 "서버에서 geometry 규칙으로 mm 정수"였지만 04_API 2.1·6.1절("좌표 변환·mm 정수화는 로컬 domain이 한다")을 따랐다. apps/web이 domain·geometry에 의존하지 않고(의존성 추가는 소유 밖), 화면이 `mToMm`(half-away, 10진 문자열)으로 절대 좌표를 먼저 mm로 바꾼 뒤 정수 원점(최소 x·y를 m 단위로 내림)을 빼므로 부동소수 뺄셈 오차가 없다. 서버는 형식·범위·크기만 검사.
2. **features 의존성 추가**: `packages/features/package.json`에 `@arch-studio/geometry`·`@arch-studio/io`(workspace) 2줄 + lockfile importer 6줄. 새 외부 패키지 0. 화면이 importDxf·normalizePolygon·area를 부르려면 필요하다(지시 "packages/io importDxf"). 소유 경계 밖 파일이라 보고한다.
3. **DXF 파싱 위치**: 02장 92행은 drafting.worker `import_dxf`지만 워커 핸들러가 아직 "구현되지 않았습니다"(apps/desktop 소유)이고 프로토콜 `unit_hint`가 `mm|m`뿐이라 io 단위 집합(`mm|cm|m|in|ft`)과 맞지 않는다. 지금은 화면이 `import("@arch-studio/io")`를 동적 import해 메인 스레드에서 파싱한다(20MB 약 1.5초 멈춤, 029 로그 수치). 후속: 워커 핸들러 구현 + 프로토콜 `unit` 확장 후 `useEngine()`으로 옮김.
4. **조회 2단계 순서**: 04_API는 "HMAC → record → 어댑터"지만 주소·지번 질의는 PNU를 알아야 해시를 만들 수 있다. PNU 질의는 문서 순서 그대로(기록 먼저, 제공자 0회), 주소·지번은 지오코딩 + 점 필지 조회(2회)로 PNU를 확정한 뒤 기록하고, 같은 필지 응답은 재사용(재호출 없음) → 용도지역 1회.
5. **용도지역 데이터셋**: `LT_C_UQ111`(용도지역) 점 질의 1회. 첫 값은 `use_district`, 나머지는 `districts`. 용도지구(`LT_C_UQ112` 등)·접도(도로 폭)는 넣지 않았다(제공자에 도로 폭 정보가 없어 `roads: []`, 사용자가 변마다 입력). 03장 3.4 "접도 표시"는 사용자 입력으로 대체.
6. **AR021 세부 사유** `details.reason`(`not_configured`·`not_found`·`timeout`·`network`·`http_status`·`too_large`·`invalid_response`) + `next:"draw"`를 더했다(04_API에 없음, 제안). 007 클라이언트 `pickSafeDetails`가 `reason`만 통과시키므로 화면은 사유별 문구를 고른다.
7. **해시 키 503 코드** `site_lookup_unavailable`(04_API에 없음): 해시 키가 32자 미만이면 상한 기록을 할 수 없으므로 제공자를 부르지 않고 503.
8. **기능 끄기**: env 스키마를 못 바꿔 "키 없음 = 꺼짐"(02장 445행) + 코드 상수 `SITE_LOOKUP_PROVIDER_ENABLED`. 화면은 조회 없이도 완결(직접 그리기 기본·DXF·저장).
9. **편집 권리 판정 중**에는 편집 컨트롤을 비활성(실패 닫힘)하고 잠금 안내는 거부가 확정됐을 때만 보인다.
10. 정북 각도 규약은 rules/envelope/north.ts의 가정(+Y에서 시계 방향, 팀장 확인 필요)을 그대로 화면 도움말에 적었다.
