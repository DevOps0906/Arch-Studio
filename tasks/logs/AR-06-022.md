# AR-06-022 번들 글꼴(Noto Sans KR)·PNG(resvg) 마무리 (2026-10-29)

대표 결정: (1) 번들 기본 글꼴 = Noto Sans KR(OFL 1.1), 나눔고딕 폐기. (2) PNG 래스터화 = 처음 sharp로 지정 → **resvg(@resvg/resvg-js, MPL-2.0)로 변경**(설치형 Rust에서 같은 렌더러를 쓰기 위해). sharp 의존성은 넣었다가 제거했다(package.json·lock에 남지 않음).

## 산출
- 글꼴: `packages/drafting/fonts/{NotoSansKR-Regular.subset.ttf, NotoSansKR.metrics.json, OFL.txt, README.md}`, `scripts/font-metrics/subset.sh`(부분 집합 재현), `generate.ts` 안내 갱신. 나눔고딕 폭 표 삭제.
- PDF: `writers/pdf/{bundled.ts(상수), node.ts(loadBundledFont·loadBundledMetrics, Node 전용 하위 경로 `./writers/pdf/node`)}`. `OutputFailure`에 `font_unavailable`·`png_failed` 추가, `png_not_implemented` 삭제.
- SVG: 기본 `font_family` = `'Noto Sans KR', sans-serif`, `SVG_WRITER_VERSION` svg-1.1.0, 골든 25건 갱신(diff는 루트 `<svg>` 줄의 font-family·data-writer-version과 meta.json·manifest뿐).
- PNG: `writers/png/{index.ts(writePng·buildPngSvg), types.ts, README.md, png.test.ts}`, 골든 `golden/png-{site-a3-basic,korean-long-names,hatch-ansi31}` + `golden/png-tools/{harness,update}.ts`. 루트 `src/index.ts`는 PNG 타입만 내보낸다.
- 문서: THIRD_PARTY_NOTICES.md(Noto Sans KR OFL, jsPDF 트리, resvg MPL-2.0 소스 위치).

## 결정·가정(대표·팀장 확인 필요 표시)
- 글꼴: 현대 한글 11,172자 + 기호 부분 집합(2.72MB) 채택(전체 6.19MB·KS X 1001 2,350자 0.74MB와 비교, 근거 `fonts/README.md`). Bold 미번들. **RFN 'Source'는 글꼴 이름에 쓰이지 않아 이름 변경 없이 부분 집합을 배포 가능하다고 판단 — 법무 확인 필요(법률 자문 아님).**
- 부분 집합 밖 글자(한자 등): `.notdef`가 빈 글리프 → 빈칸 + AR057 경고(PDF·PNG), SVG는 화면 대체 글꼴.
- resvg-js 2.6.2는 `fontBuffers`가 없어 `fontFiles`(경로)만 가능 → `PngOptions.font_file`은 경로.
- 골든 비교는 같은 환경이면 바이트, 다르면 픽셀 허용오차(플랫폼 간 바이트 동일 불보장). `input.svg`·옵션·렌더러 버전을 골든에 기록해 AR-06-080(설치형 Rust resvg)이 재현·비교한다.
- 설치형 PNG는 구현하지 않았다 → **후속 결정 항목**: Rust resvg 크레이트(추천) vs WebView canvas(결정성 없음). 상세 `writers/png/README.md`.
- pnpm 빌드 스크립트 승인 변경 없음(resvg-js는 설치 스크립트 없는 사전 빌드 바이너리).
- 소유 경계 밖 점검: `scripts/samples/build.ts`·`apps/web`은 이번 변경으로 깨지지 않았다(typecheck·lint 통과). 샘플의 SVG는 새 기본 글꼴 이름을 쓰게 되므로 샘플 산출물을 다시 만들면 font-family가 바뀐다(수정하지 않음).
