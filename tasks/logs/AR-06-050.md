## [리뷰 반영] (REQUEST_CHANGES 대응)
- 🔴1: DB 요청 크기 `min(k*배수, 50)`, k·p_k 는 1..50 계약(search.py docstring). InMemoryStore.search 는 범위 밖이면 ValueError(22023 대응).
- 🔴2: 필터 후 k 미달이면 배수 2배씩 재조회(상한 50). `SearchResult(hits, insufficient, truncated)` 반환: insufficient = k 미달, truncated = 50 상한까지 받고도 미달(더 있을 수 있음). 만료본이 상위를 채우는 테스트·플래그 테스트 추가.
- 🔴3: 개정 6문항은 정답 버전 1위 + 오답 버전 부재를 단언(`WRONG_VERSION`). 필터 없는 DB 결과에 오답이 섞임을 보이는 대조 테스트. 개정 경계 테스트도 전체 결과 단언.
- 🔴4: 저장 키 (org, collection, id). 타 조직·타 컬렉션 같은 doc_id 비덮어쓰기 테스트.
- 🟡: 색인은 doc 단위 교체(`replace_document`), 줄어든 문서 테스트. 격리 테스트에 len(hits)>0 대조. application_date 는 KST `date`, datetime 은 TypeError. InMemoryStore 는 공개 컬렉션 경로 비범위(docstring; DB 는 자기 org+등록 공개 컬렉션, 타 조직 컬렉션 42501).
