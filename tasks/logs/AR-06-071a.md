# AR-06-071a 로그

## [DECISION] D-071a 웹 스튜디오 구조 — 2026-10-29 대표님
- 결정: **Vite SPA 하나 + web 어댑터 + 정적 호스팅**. 설치형(apps/desktop)과 같은 Vite 앱을 웹에도 배포한다. Next `(studio)` 공유안은 채택하지 않는다.
- 근거(spikes/studio-shell/RESULT.md, 6403f84): 초기 JS gzip Vite 89KB vs Next 183~185KB. CSP `script-src 'self' 'wasm-unsafe-eval'`에서 Vite 위반 0, Next는 인라인 RSC 스크립트 차단(nonce 시 전 경로 동적 렌더).
- 따라오는 결정: 웹 스튜디오 인증은 **Bearer**(쿠키+CSRF 아님) — 열린 결정 "웹 인증 방식" 해소. 접근 통제는 클라이언트 가드 + RLS.
- 후속 문서 작업: ADR-001 2장 경계 규칙, 06_AGENT_PLAN AR-06-071(쓰기 경로 `(studio)` → Vite 앱, CSP·세션), AR-06-072 어댑터 범위.
- 미검증: WebView2 안 실행, 실제 정적 호스트 설정, 엔진 워커·WASM 로드 → AR-06-071에서 확인.
