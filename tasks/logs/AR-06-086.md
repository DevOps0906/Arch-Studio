# AR-06-086 도면 주석 편집층

## [DECISION] 2026-11-02 착수 전 challenger(REVISE) 반영 — 팀장 결정
1. 완료 조건 재정의: 주석 없는 시트의 **기하·레이어·그리기 바이트는 불변**. `A-ANNO-USER` 레이어는 사용자 주석이 1건 이상일 때만 레이어 표·SVG 그룹에 낸다(STD_LAYERS에는 넣되 출력은 사용 시만). 입력 키 이름 변경으로 바뀌는 input_hash 파생 바이트(sheet.sha256·SVG data-input-hash·PDF 파일 ID)만 골든 재발급 허용 — 커밋 본문에 사유 명시. 그 밖의 바이트 차이는 실패로 본다.
2. 저장 키 `arch.sheets.v1` → `v2` 승격. v1은 읽기만 하고 지우지 않는다(구버전 롤백 안전). 이행 함수는 `parseStored`의 safeParse **앞**에서 실행, 1건 실패가 전체를 비우지 않도록 항목 단위로 버리고 개수 보고.
3. 이행 규칙: 같은 target 항목을 기존 annotate 의미대로 먼저 합친 뒤(뒤 항목이 이김) `id = "ov-" + target` 1건. `note:` target → `kind:"text"`, 앵커 없음(용지 좌표 고정). 오프셋 정밀도는 기존 코드와 같은 0.01mm 반올림(이행 시 위치 이동 0).
4. id 규칙: 사용자 주석 id는 `u-` 접두, 이행분은 `ov-`, 엔진 anno_id(`dim:` 등)와 충돌 불가. 스키마가 형식·시트 내 유일성 강제. 겹치면 예외가 아니라 검증 오류.
5. 앵커: `ref`(모델 객체 id) + `part`(vertex·edge·center) + `index` + `at`. id 없는 대상은 예약 ref `site:boundary`·`road:<edge_index>`·`line:setback`. 앵커에 기준 좌표 스냅샷(mm 정수)을 저장하고, 해석 좌표가 스냅샷과 다르면(인덱스 밀림) 고아로 처리 — 법정 도면에 틀린 위치로 찍히는 것보다 빼고 알리는 쪽.
6. 고아: ref 없음·index 범위 밖·스냅샷 불일치 → 출력 0건, `unapplied`에 id 기준·사유 코드(orphan_missing·orphan_index·orphan_moved)로 반환. 그 시트 뷰에 그려지지 않는 객체(다른 층 등)는 고아 아님, 그냥 그리지 않음(개수에 포함 안 함).
7. 사람 치수(`kind:"dim"`, `u-`)는 source_ref 검사 면제 대신 `source_ref:"user"` 고정 부여.
8. 상한: 시트당 주석 500개, 문자 200자. 정렬은 기존 cmpStr(UTF-16), localeCompare 금지.
9. 쓰기 범위 추가: `apps/api/app/ai/products/arch/schema.py`(AnnotationOverride→Annotation, extra=forbid 유지), `apps/desktop/src/workers/drafting.handlers.ts`(unapplied 전달). 데스크톱 SQLite `sheets.annotation_overrides` 열은 미사용이므로 건드리지 않음.
10. engine_version은 올리지 않는다(AR059 안내 회피) — 출력 기하 불변이므로.
