# AR-06-006 로그 — Rust 로컬 명령(로컬 DB·마이그레이션·스냅샷, fs 열기, export 저장)

## [DECISION] S-5 로컬 SQLite 암호화 — 2026-10-29 (사용자 결정)
- 결정: **평문 SQLite + OS 디스크 암호화(BitLocker·FileVault) 의존**. SQLCipher 미채택.
- 위치: OS 앱 데이터 폴더(`app_data_dir`)/`arch-studio.db`. 토큰·키·비밀은 OS 키체인만(SQLite·로그·설정 파일 저장 금지).
- 반영: `docs/file/03-설계/09_SECURITY_PLAN.md` S-5 행.

## [DECISION] 업데이트 전 스냅샷·마이그레이션 실패 정책 — 2026-10-29 (사용자 결정)
- 스냅샷: SQLite 백업 API로 `app_data_dir/backups/pre-migrate.db.tmp`에 쓰고 rename → `pre-migrate.db` 1개만 유지. 빈 DB(user_version 0)는 지킬 데이터가 없어 생략.
- 스냅샷 실패 = 마이그레이션 하지 않고 **읽기 전용으로 시작**(`AR061`). 마이그레이션 단계 실패(단계별 트랜잭션 롤백)와 앱보다 새 스키마(user_version > 최신)도 읽기 전용.
- DB 열기 실패·`quick_check` 실패는 `AR060`(모든 local_db 명령이 같은 코드 반환).
- 반영: `docs/file/03-설계/04_API.md` 7.3절 `AR060`·`AR061`.

## 구현 요지
- 의존성(정확 고정): `rusqlite =0.41.1`(bundled, backup; MIT, libsqlite3-sys MIT), `tauri-plugin-dialog =2.8.4`(Apache-2.0 OR MIT, Rust API만), `serde`·`serde_json`·`sha2 0.10.9`·`uuid 1.29(v7)`(기존 트리에 있던 버전). GPL·AGPL 0(`cargo tree -f "{l}"`; `secscan license`는 Cargo.lock 라이선스 정보를 못 읽음). dialog가 `tauri-plugin-fs` 크레이트를 전이 의존으로 가져오지만 플러그인 등록·권한 부여는 없다.
- 명령 6개(build.rs `AppManifest::commands`, 명령별 자동 권한, capability에 6개만): `local_db_list_projects`·`local_db_get_project`·`local_db_save_project(input.expectedVersion)`·`local_db_delete_project(id, expectedVersion)`·`fs_open_import(kind)`·`export_save_file`(원시 본문 + `x-export-format` 헤더).
- 로컬 DB: WAL, busy_timeout 5초, foreign_keys, `Mutex<Connection>` 1개. 저장은 리비전 덧붙이기, rev는 Rust가 올림, expectedVersion 불일치 거부, 삭제는 소프트 삭제. 입력은 `deny_unknown_fields`, id는 UUIDv7만, design_model은 JSON 객체·64MiB 상한.
- fs: 실제 확장자 기준 상한 DXF 20MiB, IFC/.3dm 100MiB. 한 핸들 열기 → is_file·len 확인 → `take(상한+1)`.
- export: 같은 폴더 `.arch-export-<uuidv7>.tmp` → fsync → rename. 결과는 `pathHash`·`bytes`·`sha256`만(경로 원문 없음).
- 마이그레이션 테스트: 재오픈 멱등, 스냅샷 선행, 스냅샷 실패 → 읽기 전용, 실패 단계 롤백, 추가 문장만(DROP·RENAME·DELETE·UPDATE·PRAGMA 금지), 적용 파일 해시 고정(CRLF 정규화).

## 사람 확인 필요
- 실제 OS 대화상자(열기·저장·덮어쓰기 확인), 특수 경로(junction·OneDrive 온디맨드·260자 초과 경로)에서 열기·저장.
