# AR-06-027 로그 — 평면 개략도 편집기 (`/projects/:id/plans`)

## 구현 요약
- `packages/features/src/plans/**`: model(설계 모델 파싱·분석)·ops(실 그리기/분할/병합/경계 이동/문창, 불변 순수 함수, 좌표는 layout·geometry만)·editor+history(실행취소 100단계)·keys(키보드)·canvas/panels(UI)·preview(엔진 sheet 레인의 floor_plan 뷰)·access(열람 잠금).
- 판정은 `useJudgment`(엔진 judge 레인)만 쓴다. 판정 실패 시 자리표시 판정으로 도면만 만든다.
- 저장은 `adapters.projects.save`(VERSION_CONFLICT 시 병합하지 않고 최신 열기). AR051(겹침·외곽 이탈·문창 범위)이 있으면 저장 차단.
- 편집 잠금: 편집 권리 없음 또는 폭 768 미만이면 열람만. `?state=loading|error|empty` 데모 지원.
- `apps/desktop/src/workers/drafting.handlers.ts`: sheet 레인에 `floor_plan` 분기 추가(AR051/AR050 오류 매핑). 테스트 `drafting.floorplan.test.ts`.
- 036 모델러(`packages/features/src/modeler`)는 수정하지 않았다.

## 문서와 다르게 한 점
- 끌어 놓기·경계 끌기는 키보드 대체 경로(놓기 버튼, `[ ]`+화살표)를 함께 제공. 폭 768 미만은 편집 불가(03장 6.4절 해석).
- 분할/병합은 축 정렬 직사각형 실만 지원(그 외는 안내 메시지).

## 미해결
- 데모에는 규칙 팩이 없어 판정 배지가 "법규 판정 실패"로 보인다(실제 엔진 연결 후 해소).
- 실↔목표 연결 키가 없어 이름 완전 일치(026과 동일). 문 swing 의미 미정의.
