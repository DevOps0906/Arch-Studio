# Arch Studio 기획·디자인 독립 교차 검토 — 2026-10-28

## 1. 총평(5줄)
1. 핵심 가치는 소형 사무소의 계약 전 제안을 근거 있는 판정과 결정적 도면으로 연결하는 데 있다([PRD](../file/02-요구사항/01_PRD.md) #1·#9.1).
2. 고객·가격 가설은 아직 미검증인데 웹·설치형 동등 제공까지 MVP가 넓어져, 검증보다 구현 부담이 앞선다([린](../file/02-요구사항/00_LEAN.md) #3·#4, [PRD](../file/02-요구사항/01_PRD.md) #2).
3. 라이선스 3종과 좌석 판매의 방향은 정해졌지만 사용자별 권한·복수 상품·기기 수 계약은 정합화가 필요하다([ADR](../file/03-설계/ADR-001_DELIVERY_AND_LICENSING.md) #4.1·#4.3·#4.5).
4. 다크 랜딩과 라이트 앱은 역할이 분명하나 반응형·상태 문구·토큰 적용에는 이전 정책과 시안 값이 함께 남아 있다([DESIGN](../../DESIGN.md) #2·#5·#6, [UX](../file/03-설계/03_SCREENS_UX.md) #1.3·#6·#8).
5. 우선순위는 기능 추가보다 검증 게이트, 법규 근거, 권한과 데이터 회수 보장을 하나의 수용 기준으로 묶는 것이다([린](../file/02-요구사항/00_LEAN.md) #2, [ADR](../file/03-설계/ADR-001_DELIVERY_AND_LICENSING.md) #3·#9).

검토 범위: 요청된 문서의 관련 장, 토큰, 시안 소스, Mermaid. 외부 시장·법령 사실의 재검증 및 브라우저 렌더링 검사는 수행하지 않았다. 아래 시장 판단은 내부 근거의 강도에 대한 평가이며, 개선안은 제안이다. `docs/source/**`는 분석하지 않았다.
