# 00 린 검증 — Arch Studio (가칭)

작성일 2026-10-28. 이 문서는 정식 개발 전 게이트다. 기능·가격·범위의 정본은 `01_PRD.md`이고, 검증 순서의 정본은 `01_PRD.md` 9.10절과 개발서 `docs/source/develop/arch-studio/arch-studio_develop.md` 1.1절이다(여기서는 가설과 기준만 모은다). 모든 수치는 PRD·개발서의 제안값이며 실측 전이다.

## 1. 검증 요약

| 항목 | 내용 |
|---|---|
| 문제 | 소규모 건축사사무소는 계약 전 무료 제안 1건에 1~2일을 쓰고, 일조사선·주차·조례를 손으로 검토한다(`01_PRD.md` 1장 이건축). 시공사는 설계사무소 회신을 1~2주 기다리다 고객을 놓친다(박소장) |
| 고객 | 1순위: 1~3인 건축사사무소(단독주택·근생). 2순위: 전원주택 시공사. 상세 페르소나 3종은 `01_PRD.md` 1장 |
| 대안(경쟁) | CAD + SketchUp 수작업, 범용 법규 검색, 설계 대행. 비교 범주·기준은 `01_PRD.md` 10장 AR-F-039 판정표 |
| 핵심 가설 | "1~3인 사무소는 대지 입력 → 법규 판정 → 배치도·면적 산정도 DXF → 제안서까지 하루 안에 끝내는 도구에 영구 라이선스 490,000원(얼리버드, 제안)을 낼 것이다" |
| 기한·비용 | 스파이크 2일 + 랜딩 공개 후 6주 + 인터뷰는 W2~W4. 비용: 개발자 시간, 호스팅 최소. 외부 지출은 `미확인` |

## 2. 가설별 검증 방법과 통과/중단 기준

| # | 가설 | 가장 싼 검증 | 통과 기준 | 중단·재검토 기준 | 근거 |
|---|---|---|---|---|---|
| H1 | 도면 품질: TS 작성기로 만든 DXF가 실무 CAD에서 열리고 치수가 맞다 | **AR-06-019 2일 스파이크**: 샘플 대지 3건(정형, 꼭짓점 많은 부정형, 일조사선 걸리는 전용주거)의 배치도·면적 산정도 DXF를 AutoCAD(사람)·LibreCAD·ezdxf audit로 연다 | 한글 포함 3건 모두 열림, audit 오류 0, 치수 일치 | 1건이라도 열리지 않거나 치수 불일치 → AR-06-020~022 중단, 사람에게 보고. AC1027 구조 원인이면 1~2일 추가, 한글 원인이면 글꼴 전략 재검토 | `01_PRD.md` 9.10절 1단계, 개발서 1.1절 |
| H2 | 수요: 샘플 도면을 받아 본 사람이 사전예약한다 | 랜딩에 샘플 DXF·PDF 다운로드(`/samples`, AR-06-033) + 사전예약 폼(결제 없음) | 다운로드 → 사전예약 **10% 이상**(6주). 사전예약 **50건 이상**(6주) | 사전예약 **5% 미만** → 가격·메시지 재검토, W5 이후 범위(평면 편집기, 3D 입출력) 보류 | `01_PRD.md` 7장·9.8절·9.10절 2단계 |
| H3 | 지불의사: 영구 490,000원 + 연 290,000원 업데이트를 살 의향이 있다 | 인터뷰 5건 이상(개발서 1.1절 질문표 중 가격 질문) | 구매 의향 응답 기준값 `팀장 결정 필요`(PRD에 수치 없음). 실제 지불은 H2의 사전예약 50건으로 확인 | `미확인` | `01_PRD.md` D-2·D-4, 개발서 1.1절 |
| H4 | 실무 적합성: 제안 준비 시간이 줄고 DXF만으로 충분하다 | 인터뷰 5건 이상: 제안 1건 소요 시간, DWG 필수 여부, 쓰는 CAD, 레이어 규칙, Windows 여부 | 판단 자료 확보(D-22 DWG, D-24 레이어, D-12 macOS, D-2 가격) | "DWG 필수" 응답 **과반** → D-22 (b) ODA SDK 비용 확인 후 사람이 판단 | `01_PRD.md` 9.10절 3단계, AR-F-040 V0 |
| H5 | 법규 신뢰: 판정과 근거 조항을 믿고 쓴다 | V0 인터뷰에 "지금 계약 전 제안을 어떻게 만드는가, 어디서 시간이 가장 드는가"를 더해 한 번에 진행(AR-F-040). 정량 판정은 평가셋 30건(베타) | 인터뷰 단계: 판단 기준은 V0 결과로 확정(`[DECISION]`). 베타: 정량 항목 정확도 **98% 이상** | 정확도 기준 미달 시 규칙 팩 릴리스 보류 | `01_PRD.md` 7장 KPI, 10장 AR-F-040 |

인터뷰 질문표 전문은 개발서 1.1절을 보고 여기에 옮기지 않는다. 사후 측정 V1(베타 5명 시간 측정)은 `01_PRD.md` 10.1절 AR-F-040.
