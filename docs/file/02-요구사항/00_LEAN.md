# 00 린 검증 — Arch Studio (가칭)

작성일 2026-10-28. 이 문서는 정식 개발 전 게이트다. 기능·가격·범위의 정본은 `01_PRD.md`이고, 검증 순서의 정본은 `01_PRD.md` 9.10절과 개발서 `docs/source/develop/arch-studio/arch-studio_develop.md` 1.1절이다(여기서는 가설과 기준만 모은다). 모든 수치는 PRD·개발서의 제안값이며 실측 전이다.

## 1. 검증 요약

| 항목 | 내용 |
|---|---|
| 문제 | 소규모 건축사사무소는 계약 전 무료 제안 1건에 1~2일을 쓰고, 일조사선·주차·조례를 손으로 검토한다(`01_PRD.md` 1장 이건축). 시공사는 설계사무소 회신을 1~2주 기다리다 고객을 놓친다(박소장) |
| 고객 | 1순위: 1~3인 건축사사무소(단독주택·근생). 2순위: 전원주택 시공사. 상세 페르소나 3종은 `01_PRD.md` 1장 |
| 대안(경쟁) | CAD + SketchUp 수작업, 범용 법규 검색, 설계 대행. 비교 범주·기준은 `01_PRD.md` 10장 AR-F-039 판정표 |
| 핵심 가설 | "1~3인 사무소는 대지 입력 → 법규 판정 → 배치도·면적 산정도 DXF → 제안서까지 하루 안에 끝내는 도구에 영구 라이선스 490,000원(얼리버드, 제안)을 낼 것이다" |
| 기한·비용 | 스파이크 2일 + 인터뷰 5건(G0 전) + 랜딩 공개 후 6주. 비용: 개발자 시간, 호스팅 최소. 외부 지출은 `미확인` |

## 2. 가설별 검증 방법과 통과/중단 기준

AC1027 구조 원인이면 1~2일 추가, 한글 원인이면 글꼴 전략 재검토 | `01_PRD.md` 9.10절 1단계, 개발서 1.1절 |

| H3 | 지불의사(**약정**): 영구 490,000원 + 연 290,000원 업데이트에 돈을 낼 의사가 있다 | 인터뷰 5건 이상(개발서 1.1절 가격 질문) → G-베타 이후 의향자에 예약금(환불 가능) 제안 | 인터뷰: 5건 중 **3건 이상** "490,000원에 구매" 응답. 약정: 예약금 **10건 이상**. **제안값, 승인 2026-10-28** | 인터뷰 **1건 이하** → 가격·상품 재설계. 2건 → 인터뷰 5건 추가. 약정 5건 미만 → G-판매 보류. **제안값, 승인 2026-10-28** | `01_PRD.md` D-2·D-4, 개발서 1.1절 |
| H4 | 실무 적합성: 제안 준비 시간이 줄고 DXF만으로 충분하다 | 인터뷰 5건 이상: 제안 1건 소요 시간, DWG 필수 여부, 쓰는 CAD, 레이어 규칙, Windows 여부 | 판단 자료 확보(D-22 DWG, D-24 레이어, D-12 macOS, D-2 가격) | "DWG 필수" 응답 **과반** → D-22 (b) ODA SDK 비용 확인 후 사람이 판단 | `01_PRD.md` 9.10절 3단계, AR-F-040 V0 |
| H5 | 법규 신뢰: 판정과 근거 조항을 믿고 쓴다 | V0 인터뷰에 "지금 계약 전 제안을 어떻게 만드는가, 어디서 시간이 가장 드는가"를 더해 한 번에 진행(AR-F-040). 정량 판정은 평가셋 30건(베타) | G0: V0 인터뷰로 판단 기준 확정(`[DECISION]`). 인터뷰 질문표 전문은 개발서 1.1절을 보고 여기에 옮기지 않는다. 사후 측정 V1(베타 5명 시간 측정)은 `01_PRD.md` 10.1절 AR-F-040.

### 2.1 단계 게이트 (순환 제거: 의향 → 약정 → 구매 순으로 증거를 올린다)

| 게이트 | 진입 조건 | 측정 지표 | 통과 | 중단·재검토 |
|---|---|---|---|---|
| G0 (W1 착수 전) | 스파이크 2일 실시, 인터뷰 5건 완료 | H1 DXF 열림·치수, H4 인터뷰, H3 인터뷰 응답 | H1 3건 통과 + 인터뷰 5건 + H3 인터뷰 3건 이상(제안값) | H1 실패 → AR-06-020~022 중단. H3 1건 이하 → 상품·가격 재설계 후 재판정 |
| G-베타 (베타 전) | G0 통과, 랜딩 6주 공개, 규칙 팩 법규 검토 서명 | **의향**: 다운로드 → 등록 비율·건수 | 의향 10% 이상 + 50건 이상, 법규 서명 완료 | 의향 5% 미만 → 메시지·가격 재검토, 베타 보류 |
| G-판매 (유료 판매 전) | G-베타 통과, 베타 사용자 5명 이상 | **약정**: 예약금 건수. 정확도 98%(평가셋 30건), 오통과 0 별도 집계 | 약정 10건 이상 + 정확도 98% 이상(모두 제안값, 승인 2026-10-28) | 약정 5건 미만 또는 정확도 미달 → 판매 보류 |
| 판매 후 | 판매 개시 | **구매**: 결제 건수·전환(`01_PRD.md` 7장 KPI) | PRD 7장 | PRD 7장 |

규칙: 의향 건수를 약정·구매로 계산하지 않는다. 베타 이후 단계는 앞 게이트 미통과 시 착수하지 않는다.

- KPI "얼리버드 사전예약 50건 이상 / 사전예약 결제(또는 예약금) 건수" 행을 둘로 나눈다: "의향(무결제 사전예약) 50건 이상, 다운로드 → 등록 10% 이상 / 랜딩 공개 후 6주 / G-베타 기준" · "약정(예약금) 10건 이상 / 베타 중 / G-판매 기준(제안값, 승인 2026-10-28)".

- 9.10절 2단계 통과 기준 "측정 시작"에 "의향 지표(무결제)임"을 덧붙인다.
