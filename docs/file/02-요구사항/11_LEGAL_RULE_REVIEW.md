# 11 규칙 팩 법규 근거 검토 — Arch Studio (가칭)

작성일 2026-10-28. 근거: `01_PRD.md` 6.2절(뉴스·2차 자료 기반), Codex 검토 R5. 법령 내용은 쓰지 않는다: 원문 대조 전까지 모든 칸은 `미확인` 또는 빈칸이다. 검토자는 사람(법규 검토 담당)이다.

## 1. 확인 방법 (모든 행 공통)

국가법령정보센터(law.go.kr)에서 법령 원문·연혁을 열어 조문·공포일·시행일·부칙을 대조한다. 조례는 자치법규정보시스템(elis.go.kr)에서 지원 지역별로 대조한다. 뉴스 기사는 근거로 쓰지 않는다.

## 3. 지원 범위 결정 (팀장·사람 결정)

| 항목 | 결정값 |
|---|---|
| 지원 지역(시·군·구) | `팀장 결정 필요` |
| 지원 용도(예: 단독주택, 근린생활시설) | `팀장 결정 필요` |
| 기준일(규칙 팩이 반영한 법령·조례 시점) | `팀장 결정 필요` |

## 4. 미지원 판정 정책

| 상황 | 처리 |
|---|---|
| 지원 지역·용도 밖 | 판정하지 않고 "미지원: 직접 확인 필요"로 표시, 합격·불합격 표시 금지 |
| 조례 미확인(해당 지역 행 서명 전) | 정량 판정 차단, 국가 기준 참고값이라는 경고만 |
| 신청 예정일이 시행일·기준일 전후 불명 | 신·구 규칙을 병행 표시하고 선택은 사용자 |
| 상태가 `미확인`인 항목 | 규칙 팩에 "확정" 규칙으로 포함하지 않음("예정 규칙" 또는 경고만) |

## 5. 규칙 팩 승인 조건

- 2절 표에서 해당 릴리스에 포함한 모든 행: 근거 조문·공포일·시행일 기입, 원문 대조, 검토자·확인일 기입.
- 3절 지원 범위·기준일 확정, 4절 정책이 화면·판정 결과에 반영됨.
- 사람 법규 검토 서명: 이름·일자는 아래에 기록한다(AI는 서명할 수 없다). 서명 없이는 `00_LEAN.md` G-베타 불통과.
- 평가셋 30건 정확도와 오통과를 항목별로 별도 집계(기준은 `00_LEAN.md` 2.1절 G-판매).
- 법령 개정 시 해당 행 상태를 `미확인`으로 되돌리고 재서명한다.
