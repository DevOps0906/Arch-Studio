# 10. 제공 방식 벤치마크 — 웹 SaaS + 설치형 하이브리드

> 확인일: 2026-10-28 (WebSearch/WebFetch). 공식 문서로 확인 못 한 항목은 '미확인' 또는 '(2차 출처)'로 표시했다.
> 목적: "웹에서 바로 쓰기 / 랜딩에서 설치형 받기" 구조를 정하는 근거 자료. 결정은 ADR로 따로 남긴다.

## 1. 요약
- 조사한 9개 제품 중 **웹만 있는 제품**(Onshape·Snaptrude)과 **데스크톱이 본체이고 웹은 일부 기능만 있는 제품**(SketchUp·AutoCAD·Fusion·Rhino)으로 나뉜다. 웹과 데스크톱 기능이 같은 제품은 Figma뿐인데, Figma 데스크톱은 사실상 브라우저를 감싼 앱이다.
- **같은 계정·같은 구독으로 웹과 데스크톱을 모두 쓰는 방식**은 Autodesk(AutoCAD·Fusion), SketchUp Pro/Studio, Figma가 똑같이 쓴다. 웹에만 따로 값을 매긴 예는 SketchUp Go와 AutoCAD Web 단독 상품이다.
- **영구 라이선스와 웹을 함께 파는 곳은 McNeel(Rhino)뿐**이다. 그런데 McNeel은 웹 편집기를 내지 않고, 웹 연산(Rhino.Compute)만 사용 시간 기준으로 과금한다. Archicad(2026년부터)와 Vectorworks(2023년부터)는 영구 라이선스를 없애고 구독으로 옮겼다.
- 오프라인 사용은 데스크톱에만 있고 기간 제한이 붙는다. Fusion은 2주, Autodesk 구독 제품은 30일마다 다시 접속해야 한다. 웹 쪽 오프라인 지원은 조사한 어느 제품에서도 확인되지 않았다.
- **권장안은 B(데스크톱 우선 + 웹 체험·뷰어)를 기본으로 하고, 엔진 공유 덕분에 웹 체험을 넉넉하게 여는 방식**이다. 오프라인 판정과 0크레딧 도면 기능, 영구 라이선스라는 현재 기획의 차별점을 그대로 지키면서, 웹은 가입 전환 경로로 쓴다.

## 3. 반복 패턴
1. **계정·구독 하나로 웹과 데스크톱 모두 사용**: Autodesk·SketchUp Pro·Figma. 가격 등급은 플랫폼이 아니라 기능으로 나누고, 웹만 쓰는 하위 등급(SketchUp Go·AutoCAD Web 단독)을 진입 상품으로 둔다.
2. **웹은 가볍게·협업용, 데스크톱은 무거운 작업용**: AutoCAD Web(2D만), Fusion 웹(애드인 불가), SketchUp Go(확장 기능 없음). 웹에서 빠지는 기능은 확장 기능, 로컬 폰트·파일 접근, 3D 고급 기능이다.
3. **클라우드에 저장하고 데스크톱이 캐시**: Fusion(오프라인 2주 후 재동기화)과 AutoCAD(30일 재인증). 오프라인은 "제한 기간이 있는 예외 상황"으로 설계한다.
4. **웹 전용 제품은 설치형이 아예 없다**: Onshape·Snaptrude는 "설치 없음"을 장점으로 내세운다. 대신 오프라인을 포기하고 연간 구독(Onshape $1,500~)이나 크레딧제(Snaptrude)를 쓴다.
5. **업계는 영구 라이선스에서 구독으로 이동 중**: Vectorworks(2023), Archicad(2026)가 전환했다. 남은 예외인 Rhino는 웹 편집기를 내지 않고 웹 연산만 사용량 과금으로 따로 판다.
6. **AI와 무거운 연산은 크레딧이나 사용량으로 과금**: Snaptrude 크레딧, Rhino.Compute의 코어·시간 과금. Arch Studio의 AI 크레딧 모델과 같은 흐름이다.

## 4. Arch Studio 적용안
전제: 엔진(지오메트리·법규 판정·DXF)이 순수 TS라 브라우저에서도 그대로 돈다. 그래서 어느 안을 고르든 **웹 판정을 추가하는 비용은 UI 껍데기와 저장소 정도**다.

| 항목 | A. 웹 우선 + 설치형은 오프라인 보강 | B. 데스크톱 우선 + 웹은 체험·뷰어 (**권장**) | C. 웹과 설치형 동등 |
|---|---|---|---|
| 형태 | 웹 앱이 본체(Supabase 저장). Tauri는 오프라인과 로컬 파일용 | Tauri가 본체(SQLite·키체인·오프라인). 웹은 체험(저장·내보내기 제한)과 공유 링크 뷰어 | 기능이 같은 두 클라이언트. 클라우드 동기화 필수 |
| 장점 | 설치 없이 바로 가입 가능, 업데이트 한 번에 배포, Onshape·Snaptrude형 | 현재 기획(오프라인 판정·도면 0크레딧·영구 라이선스·기기 2대)을 그대로 유지. 웹은 전환 경로 역할 | 사용자가 선택 가능, Figma형 경험 |
| 단점 | 오프라인·0크레딧 차별점이 약해짐. 클라우드 저장·RLS·동기화 비용이 처음부터 듦 | 첫 사용 전에 설치라는 마찰. 웹 체험 범위를 잘 정하지 않으면 전환이 약함 | 동기화 충돌 해결, 두 플랫폼 QA, 기능 차이 관리 비용이 가장 큼 |
| 비용(상대) | 중~상 (서버 저장소·동기화) | 하~중 (웹 체험은 엔진 재사용, 저장은 로컬) | 상 |
| 위험 | 웹에서 법규 판정을 무료로 무제한 쓰면 크레딧·라이선스 모델이 흔들림. 클라이언트 코드 노출 | 웹 체험에서 엔진 번들이 그대로 공개됨(판정 로직 노출) → 체험판은 저장·DXF 내보내기만 막으면 충분한지 판단 필요 | 영구 라이선스 사용자가 클라우드 동기화를 쓸 때 서버 비용을 누가 낼지 모호 |
| 영구 라이선스와의 관계 | **충돌**: 웹 본체는 계속 서버 비용이 들어 영구 라이선스와 맞지 않음(업계도 구독으로 이동) | **잘 맞음**: Rhino 모델(영구 데스크톱 + 사용량 과금 웹·AI)과 같은 구조 | 부분 충돌: 영구 라이선스는 데스크톱만, 웹·동기화는 구독으로 나눠야 함 |

**권장: B.** 근거는 다음과 같다.
1. 영구 라이선스와 웹 본체를 함께 운영하는 사례는 조사 범위에서 없었다. 영구 라이선스를 지키는 Rhino는 데스크톱을 본체로 두고 웹 연산만 사용량으로 과금한다.
2. 오프라인과 0크레딧 도면이 차별점이다. 경쟁 웹 제품(Onshape·Snaptrude)은 오프라인이 없거나 확인되지 않고, Snaptrude는 크레딧제다.
3. 엔진이 TS라서 웹 체험판은 거의 비용 없이 만들 수 있다. "웹에서 바로 판정해 보기"를 랜딩의 첫 행동으로 둘 수 있다(SketchUp Go·AutoCAD Web 같은 진입 역할).
4. 월 구독 사용자에게는 나중에 Autodesk처럼 "같은 계정으로 웹 편집"을 붙여 C로 넓힐 수 있다. B에서 C로 가는 길은 열려 있지만, A에서 영구 라이선스로 돌아오기는 어렵다.
- 웹 체험 경계(제안): 판정·3D 보기는 허용하고, 프로젝트 저장은 브라우저 IndexedDB 1건, DXF 내보내기와 AI는 로그인과 크레딧이 필요하다. 이 경계는 PRD에서 확정할 일이다.

| 채널 | Stable 하나로 시작하고 필요하면 Beta를 둔다. 이전 버전 보관 페이지 | VS Code Stable/Insiders, Rhino 이전 버전 보관 페이지 |
| 다운로드 후 동선 | 설치 → 첫 실행에서 웹 로그인(브라우저 딥링크) → 라이선스를 기기에 등록(2대 중 1) → 오프라인 사용 가능 표시 | Rhino 평가판·라이선스판 선택 흐름 |
| 평가판 | "평가판 N일, 저장·DXF 제한" 정책을 다운로드 버튼에 한 줄로 표시 | Rhino 90일 평가판(90일 뒤 저장·플러그인 중지), AutoCAD Web 30일 후 읽기 전용 |
| 모바일 방문자 | 다운로드 대신 "웹 뷰어 열기"와 "PC로 링크 보내기(이메일)" | Figma·Onshape 모바일 앱 대응(Arch Studio는 앱 없음) |

## 6. 미확인 목록
- Fusion 웹 클라이언트가 지원하는 기능의 공식 범위(2차 출처만 있음), 웹 오프라인 지원 여부, 다운로드 페이지 구성
- Onshape 오프라인 지원 여부(공식 언급 없음)
- SketchUp 웹 기술 스택(WASM 여부), 데스크톱 오프라인 기간 제한, 무료 등급이 남아 있는지(2차 출처끼리 엇갈림), 월 결제 가격
- AutoCAD Web 렌더링 기술, 웹 단독 가격(앱스토어 기준 값만 있음)
- Figma 데스크톱의 프레임워크(Electron 여부)와 오프라인 편집 범위(공식 문서 없음)
- Rhino.Compute 현재 공식 단가(2020년 공지와 AWS 미리보기 글만 있음), Cloud Zoo로 쓸 수 있는 기기 수
- Snaptrude 데스크톱 앱 존재 여부, 오프라인 지원 여부
- BIMx 웹 뷰어 범위, Archicad 오프라인 인증 주기
- Vectorworks 웹 뷰어 범위
- Spline 데스크톱 앱 역할, 오프라인 지원 여부, 가격
- 조사 제품 중 **랜딩에 SHA-256 체크섬을 표시하는 곳**은 확인하지 못했다(Figma·VS Code·Rhino 모두 표시 없음). 따라서 5장의 체크섬 표시는 업계 관행이 아니라 이 문서의 제안이다.
