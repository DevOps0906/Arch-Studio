# 09 SECURITY PLAN: Arch Studio 보안 관리 계획

보안 레벨·자산·위협·키·공급망·개인정보·운영·릴리스 점검을 한 곳에 모은다. PRD는 요약만 둔다(`../02-요구사항/01_PRD.md` 12장).
수치·주기는 별도 표기가 없으면 제안이다(근거 없음, 신규 제품). 법령 해석은 단정하지 않고 `확인 필요`로 둔다.
정본: 코어 규칙 `공용코어/SECURITY_BASELINE.md`(이하 SB), 위험 14건 `02_ARCHITECTURE.md` 6절, 작업 `../01-관리/06_AGENT_PLAN.md` 5.3절.
