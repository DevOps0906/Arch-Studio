## 3. 상태 바꾸는 법

1. 증거가 준비되면 "검증 방법" 열대로 확인한다.
2. 상태와 확인일을 고치고, 바꾼 이유를 task `log.md`에 `[DECISION]`으로 남긴다.
3. 측정 결과가 주장과 다르면 "폐기"로 바꾸고 문장을 다시 쓰지 않는다(LANDING_PERSUASION.md 3.4절 상태 규칙).
