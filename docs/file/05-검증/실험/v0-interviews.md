# V0 인터뷰 질문지와 기록

> 작업 AR-06-066(AR-F-040), P0. 진행은 대표님(사람)이 한다. 이 문서는 질문지와 빈 기록 칸만 둔다. 결과는 인터뷰 후 사람이 채운다.
> 근거: `docs/file/02-요구사항/01_PRD.md` 9.10절 3단계(인터뷰 5건 이상, D-22 판단 자료), 10.1절 AR-F-040, `docs/file/03-설계/디자인/LANDING_PERSUASION.md` 3.6절 V0 인터뷰.

## 1. 진행 원칙

- 대상: 소형 건축사사무소 실무자 5명 이상(01장 1장 페르소나).
- 한 번의 인터뷰에서 PRD 9.10절 3단계 질문과 제안 준비 질문을 함께 묻는다.
- 제품 설명은 마지막에만 한다. 앞 질문에서 불편을 유도하지 않는다(장면 문장을 먼저 읽어 주지 않는다).
- **실명 기록 금지.** 사무소 이름·사람 이름·연락처·주소는 이 문서와 녹음 파일 이름에 쓰지 않는다. 참여자는 익명 코드(V0-P01, V0-P02, …)로만 적는다. 코드와 실제 참여자의 대응은 저장소 밖에 둔다.

## 2. 질문지

| 순서 | 질문 | 근거 | 무엇을 듣나 |
|---|---|---|---|
| Q1 | 지금 계약 전 제안을 어떻게 만드시나요? 처음부터 끝까지 순서대로 말씀해 주세요 | AR-F-040 | 현재 방법·도구 |
| Q2 | 그중 어디서 시간이 가장 드나요? 제일 짜증 나는 곳은요? | AR-F-040, LP 3.6절 | 먼저 꺼내는 불편(장면 AS-C-01~03 해당 여부) |
| Q3 | 최근 제안 한 건에 실제로 얼마나 걸렸나요? | AR-F-040 | 참여자가 말한 시간(그대로 받아 적는다) |
| Q4 | 배치도·면적 산정도를 DXF로 받으면 제안 시간이 얼마나 줄어들 것 같나요? | PRD 9.10절 3단계 | 예상 단축 정도 |
| Q5 | DWG가 꼭 필요한가요? DXF를 쓰시는 CAD에서 열어 DWG로 저장하는 방식은 어떤가요? | PRD 9.10절 3단계, D-22 | 꼭 필요 / 필요 없음 / 상관없음 |
| Q6 | (제품 설명 후) 방금 본 내용 중 지금 방식보다 낫거나 못한 점은요? | LP 3.6절(제품 설명은 마지막) | 반응, 우려 |

## 4. 판정 기준

기준값은 근거 문서의 제안값이다. 인터뷰 결과를 보고 사람이 확정하며, 확정한 기준과 결과를 함께 `[DECISION]`으로 남긴다.

| 판정 | 기준(제안) | 근거 | 통과하면 | 실패하면 |
|---|---|---|---|---|
| 불편 확인 | 5명 중 3명 이상이 같은 불편을 먼저 꺼낸다 | LP 3.6절 V0 인터뷰 | 해당 장면 주장(AS-C-01~03)의 장부 상태 변경을 검토 | 판정 기준을 고치거나 페르소나를 바꾼다. 같은 불편이 안 나오면 제품 범위 재검토 |
| D-22 DWG | "DWG가 꼭 필요하다" 응답이 과반 | PRD D-22 | (b) ODA SDK 비용을 확인한다 | (a) 미지원, DXF만 유지 |
